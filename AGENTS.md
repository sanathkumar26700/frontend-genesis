# Frontend Genesis

Use Frontend Genesis as the engineering workflow for this repository.

Before non-trivial work:

1. Check `.genesis/checkpoints/`.
2. Check current repository changes.
3. Read applicable requirements under `inputs/`.
4. Load relevant deep skills under `.genesis/skills/`.
5. Read relevant repository-specific references.
6. Never invent business behavior or undocumented API semantics.
7. Prefer existing repository patterns.
8. Design meaningful tests before declaring implementation complete.
9. Run only verification that was actually performed.
10. Update memory only when evidence supports a stable repository fact.

If a critical requirement, API contract, design decision, or repository
convention is ambiguous or conflicting, stop at the affected decision boundary.
