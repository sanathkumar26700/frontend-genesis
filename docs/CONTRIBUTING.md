# Contributing

A deep skill must teach execution, not merely state a principle.

Each skill should contain:

- purpose
- activation
- required context
- evidence
- procedure
- decision rules
- implementation guidance
- edge cases
- anti-patterns
- verification
- outputs
- stop conditions
- self-review
- interactions

Do not add repository-specific assumptions to generic skills.

If a pattern is repository-specific, teach Genesis how to discover it and store
the result in `.genesis/`.
