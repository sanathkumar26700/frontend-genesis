# Operating Model

```text
Boot
 ↓
Awareness check
 ↓
Requirements
 ↓
Repository evidence
 ↓
Skill routing
 ↓
Impact analysis
 ↓
Test design
 ↓
Implementation
 ↓
Verification
 ↓
Independent review
 ↓
Memory update
 ↓
Checkpoint
```

Repository memory is not a replacement for source inspection. It is a durable
summary that makes future discovery faster and more accurate.
