# Visual Verification


## Purpose

Compare implemented UI against supplied design evidence and current repository
visual conventions.

## Procedure

1. Identify reference state.
2. Compare structure.
3. Compare layout/spacing.
4. Compare typography.
5. Compare component states.
6. Compare responsive behavior.
7. Compare assets/icons.
8. Check dynamic content.
9. Record material differences.

Do not claim pixel-perfect fidelity without an actual reference comparison.


## Universal skill rules

- Treat repository evidence as potentially stale.
- Distinguish Observed, Inferred, and Unknown.
- Do not invent business requirements.
- Do not invent undocumented API behavior.
- Prefer existing repository patterns.
- Do not introduce dependencies or abstractions without justification.
- Report uncertainty at the decision boundary where it matters.
- Never claim verification that was not actually performed.
