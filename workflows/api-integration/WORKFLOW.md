# API Integration Workflow

1. Read supplied API documentation.
2. Extract exact transport contract.
3. Discover repository API architecture.
4. Discover DTO/generated-type/transformer/mapper/domain-model usage.
5. Preserve auth and error conventions.
6. Preserve cache/invalidation conventions.
7. Implement through the existing data boundary.
8. Add contract/transformer tests.
9. Add behavior tests.
10. Verify runtime network behavior when possible.
11. Trace implementation to API and product requirements.
