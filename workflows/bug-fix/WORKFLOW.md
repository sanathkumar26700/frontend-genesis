# Bug Fix Workflow

1. Establish expected behavior.
2. Reproduce the failure if possible.
3. Trace the causal path.
4. Identify root cause.
5. Add regression test.
6. Implement the smallest root-cause fix.
7. Run focused tests.
8. Run impacted broader tests.
9. Browser verify if user-visible.
10. Review adjacent regression risk.
11. Update memory only if stable knowledge changed.
